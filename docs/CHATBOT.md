# Chatbot

O Assistente Qualimax v1.1 é local e baseado nos dados do catálogo.

Ele não usa API externa de IA e não deve conter chaves secretas no frontend.

O chatbot reconhece consultas relacionadas a produtos, categorias, quiz, atendimento e WhatsApp. Quando não puder confirmar uma informação, encaminha para a equipe.
