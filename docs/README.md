## Segurança

A política de divulgação responsável fica na raiz do repositório em [`SECURITY.md`](../SECURITY.md). O contato padronizado para pesquisadores também está em `/.well-known/security.txt`.

## Princípio de manutenção

A pasta `docs/` contém **documentação viva**. Relatórios de rodadas, auditorias antigas e notas de versões individuais foram consolidados no `CHANGELOG.md` para reduzir duplicação e facilitar a manutenção.
