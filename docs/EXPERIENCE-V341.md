# Evolução de experiência — v3.4.1

## Páginas priorizadas

| Página | Evolução |
|---|---|
| Início | atalhos personalizados por perfil e carrinho |
| Catálogo | acesso direto às ferramentas de decisão |
| Produtos | custo unitário, características, comparação, kit e carrinho |
| Carrinho | índice de revisão e análise pelo MAX |
| Minha Conta | indicadores locais da jornada |
| Pré-atendimento | rascunho privado e removível |
| Contato | cópia de endereço e abertura de rota |
| Sobre | compromissos verificáveis de transparência |
| 404 e offline | caminhos úteis de recuperação |

## Acessibilidade

Os controles utilizam elementos nativos, estados textuais, regiões nomeadas e botões com alvos mínimos. O comparador usa cabeçalhos de coluna e de linha para preservar o contexto em leitores de tela.

## Privacidade

Rascunho, perfil, carrinho e indicadores permanecem no navegador. Nenhum dado é enviado automaticamente.
