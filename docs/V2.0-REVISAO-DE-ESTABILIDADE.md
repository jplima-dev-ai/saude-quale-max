# Saúde Qualimax v2.0 — Revisão de estabilidade

Esta revisão mantém a versão 2.0 e corrige inconsistências encontradas após a introdução de IndexedDB, páginas individuais, favoritos, lista de interesse, histórico, compartilhamento e PWA.

## Correções aplicadas

- Chatbot: ao reconhecer uma categoria, os cards permanecem visíveis no diálogo e o usuário decide quando abrir a categoria no catálogo.
- Páginas individuais: passam a usar o mesmo IndexedDB para favoritos, lista de interesse e histórico.
- Compartilhamento: adicionado fallback robusto para cópia do link e mensagens de estado acessíveis.
- WhatsApp em páginas individuais: estado indisponível mais claro quando não houver número configurado.
- Marca em páginas individuais: título da página e logo passam a respeitar o nome configurado em `config.json` durante a execução.
- Service Worker: não armazena respostas HTTP inválidas e possui fallback mais seguro para navegação offline.
- Cache PWA: versão interna do cache atualizada sem alterar a versão comercial do projeto.

## Validação

- Sintaxe JavaScript validada.
- JSON validado.
- HTML analisado sem IDs duplicados.
- Referências locais de scripts, folhas de estilo, manifestos e imagens verificadas.
- 32 páginas individuais preservadas.
- ZIP final testado sem erros de integridade.

## Observação

A versão permanece **v2.0**. Esta é uma revisão corretiva/estabilizada, não uma nova versão funcional.
