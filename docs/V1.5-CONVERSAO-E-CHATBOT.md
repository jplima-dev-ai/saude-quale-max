# Saúde Qualimax v1.5

## Objetivo
Elevar conversão do catálogo e amadurecer o Assistente Qualimax.

## Alterações
- 32 copys comerciais individuais, sem preço, estoque ou promessa médica inventada.
- CTA dos cards alterado para “Quero saber mais”.
- Copy integrada aos cards, modal, busca e chatbot.
- Chatbot passa a exibir até 3 produtos relacionados dentro da conversa.
- Cada sugestão do assistente possui ação “Ver no catálogo”.
- Busca do chatbot usa catálogo real e continua sem API externa.
- Mensagens de preço/estoque encaminham para confirmação humana.

## Limites
O assistente continua determinístico/local. Não é IA generativa e não deve inventar dados comerciais ou recomendações médicas.
