# Saúde Qualimax v1.3.1 — Assistente no Hero

## Objetivo
Tornar o Assistente Qualimax imediatamente descobrível no início da landing page sem abrir o chatbot automaticamente e sem bloquear conteúdo.

## Implementado
- CTA dedicado "Abrir assistente" dentro do Hero.
- Teaser explicando que o assistente busca produtos, categorias e inicia o quiz.
- Mesmo chatbot continua disponível pelo botão flutuante.
- JavaScript atualizado para aceitar múltiplos botões `data-chat-abrir`.
- O foco retorna ao ponto exato que abriu o diálogo.
- `aria-haspopup="dialog"` e `aria-controls="chatbot-qualimax"` nos gatilhos.
- Chatbot recebe ID estável e `aria-hidden` coerente com o estado inicial.
- CTA do WhatsApp no Hero renomeado para linguagem objetiva, sem sugerir indicação profissional.

## Acessibilidade
O assistente não abre automaticamente. Isso evita deslocamento de foco inesperado. Todos os gatilhos são botões nativos e abrem o mesmo diálogo modal, preservando Escape, ciclo de Tab e retorno de foco.
