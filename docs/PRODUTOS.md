# Produtos

O catálogo é controlado por `data/produtos.json` e as categorias por `data/categorias.json`.

Cada produto deve conter dados reais e consistentes com a operação da loja. Não adicione preços, disponibilidade, benefícios médicos, avaliações ou características que não possam ser confirmados.

O sistema usa os dados para:

- cards;
- busca;
- filtros;
- detalhes;
- links de consulta pelo WhatsApp;
- integração do assistente.
