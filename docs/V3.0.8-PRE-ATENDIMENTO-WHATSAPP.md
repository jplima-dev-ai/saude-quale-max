# Saúde Qualimax v3.0.8 — pré-atendimento inteligente

## Objetivo

Transformar os CTAs de WhatsApp em uma etapa de preparação que agiliza a conversa sem exigir backend.

## Fluxo

1. cliente acessa a partir da Home, Catálogo, Produto, Minha Conta, Contato ou Max;
2. `atendimento.html` identifica a origem;
3. perfil local pode preencher nome, telefone e e-mail;
4. lista de interesse e produto de origem entram como seleção;
5. favoritos aparecem como sugestões opcionais;
6. cliente escolhe retirada, entrega ou confirmação com a equipe;
7. endereço só é solicitado quando entrega é escolhida;
8. cliente revisa e pode editar a mensagem;
9. somente o botão final abre `wa.me`.

Nenhum formulário é enviado para servidor.

## Privacidade

- dados digitados permanecem apenas na página enquanto ela está aberta;
- “Lembrar meus dados neste dispositivo” é opcional e desmarcado por padrão quando não existem dados salvos;
- quando ativado, nome, contato e endereço são armazenados em `localStorage`;
- o cliente pode revisar o conteúdo integral antes de abrir o WhatsApp;
- o WhatsApp ainda exige a ação do próprio usuário para enviar a mensagem.

## Contexto aproveitado

A página consegue aproveitar localmente:

- produto individual de origem;
- lista de interesse;
- favoritos como sugestões;
- perfil de Minha Conta;
- preferências da conversa com Max;
- origem comercial do contato.

## Hospedagem

O recurso usa apenas HTML, CSS, JavaScript, IndexedDB/localStorage/sessionStorage e `wa.me`.

Permanece compatível com GitHub Pages e Netlify estático.
