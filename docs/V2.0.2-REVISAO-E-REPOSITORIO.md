# Saúde Qualimax v2.0.2 — revisão corretiva

## Bugs corrigidos

1. **URLs após renomeação do GitHub**
   - O repositório passou para `saude-quali-max`, mas 39 arquivos ainda apontavam para `saude-quale-max`.
   - Foram corrigidos `config.json`, canonicals, Open Graph, Schema.org, sitemap e páginas de produto.

2. **robots.txt inconsistente**
   - O arquivo apontava para um sitemap em `www.saudequalimax.com`, domínio que não é a implantação atual.
   - Agora aponta para o sitemap real no GitHub Pages.

3. **Lista de interesse com falso estado disabled**
   - O CTA “Consultar lista no WhatsApp” era um link `<a>` e o JavaScript tentava usar `.disabled`, propriedade que não desabilita links.
   - O controle agora é um `<button>` real e permanece desabilitado quando a lista está vazia ou o WhatsApp não está configurado.

4. **Instagram hardcoded no rodapé**
   - As páginas principais tinham o Instagram escrito diretamente no HTML.
   - O rodapé agora usa as redes configuradas em `data/config.json`, facilitando reutilização para outros clientes.

5. **Cache PWA**
   - Cache interno atualizado para `qualimax-v2.0.2` para invalidar arquivos antigos após a publicação.

6. **Finais de linha no Git**
   - Adicionado `.gitattributes` para padronizar arquivos de texto em LF e evitar os avisos LF/CRLF observados no Windows.
