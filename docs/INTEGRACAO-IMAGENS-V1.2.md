# Integração de imagens — Saúde Qualimax v1.2

## Resultado

- 32 imagens recebidas e verificadas.
- 24 imagens específicas de produtos novos vinculadas aos produtos 9 a 32.
- Imagens institucionais/categorias fornecidas também substituíram as versões anteriores quando o nome coincidia.
- Produtos 1 a 8 continuam usando as imagens genéricas/categoria existentes, pois o pacote recebido não contém arquivos específicos com os nomes desses oito produtos.
- Cards ajustados para proporção visual 4:5, compatível com as imagens de produto 928 × 1152.
- Modal de detalhes passou a apresentar a imagem do produto em layout responsivo de duas colunas.
- `loading=lazy` e `decoding=async` preservados/adicionados no catálogo.

## Observação de acessibilidade

As imagens dos produtos possuem texto alternativo gerado a partir do nome do produto e da categoria. O modal mantém conteúdo textual completo; nenhuma informação necessária depende apenas da imagem.
