# Saúde Qualimax v3.0 — Conta local e Admin Studio

## Limite arquitetural

A v3.0 continua totalmente compatível com hospedagem estática em GitHub Pages e Netlify. Por isso, não existe autenticação remota, banco central ou edição automática do repositório.

## Minha Conta

`conta.html` reúne dados que já pertencem ao navegador do visitante:

- perfil local (nome, e-mail e telefone);
- favoritos;
- lista de interesse;
- vistos recentemente;
- consulta da lista pelo WhatsApp;
- exportação dos dados locais;
- exclusão dos dados locais.

Nenhum dado do perfil é enviado automaticamente para a loja.

## Admin Studio

`admin.html` é um editor local para o empreendedor.

Recursos iniciais:

- adicionar produto;
- editar produto;
- duplicar produto;
- excluir produto do rascunho;
- editar copy, CTA, descrição, tags e características;
- enviar imagem para IndexedDB;
- pré-visualizar produto;
- editar dados básicos da loja;
- ativar/desativar módulos;
- auditoria do rascunho;
- exportar `produtos.json`;
- exportar `config.json`;
- backup JSON;
- exportar imagens locais individualmente.

## Publicação

O Admin Studio não grava no GitHub ou Netlify.

Fluxo:

1. editar no Admin Studio;
2. exportar `produtos.json` e `config.json`;
3. baixar as imagens locais;
4. substituir/adicionar os arquivos no projeto;
5. executar `tools/sincronizar_cliente.py`;
6. executar `tools/auditar_cliente.py`;
7. publicar normalmente.

## Segurança

`admin.html` não é uma área protegida. Qualquer visitante pode abrir a URL, mas as mudanças feitas ali afetam apenas o navegador daquela pessoa.

Não existem tokens, senhas ou credenciais do repositório no frontend.

## Atalhos do Max

- `/conta` abre `conta.html`;
- `/adm` ou `/admin` abre o Admin Studio local.

Esses comandos são atalhos de navegação, não mecanismos de autenticação.


## Produtos novos e excluídos

A partir da v3.0, `tools/sincronizar_cliente.py` regenera as páginas individuais a partir de `data/produtos.json`.

Isso significa que:

- produto novo no JSON gera automaticamente `produto/<slug>.html`;
- produto editado atualiza nome, copy, imagem, categoria e metadados da página;
- produto removido do JSON tem sua página individual removida;
- sitemap acompanha o catálogo atual.

As páginas dentro de `produto/` devem ser tratadas como arquivos gerados. Personalizações manuais nessas páginas podem ser substituídas na próxima sincronização.
