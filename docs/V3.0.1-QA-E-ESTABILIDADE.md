# Saúde Qualimax v3.0.1 — QA e estabilidade da v3

## Objetivo

A v3.0.1 revisa a primeira implementação de Minha Conta e Admin Studio sem introduzir backend ou autenticação remota.

## Correções principais

### Edição de produto sem salvar

Na v3.0 era possível alterar campos e selecionar outro produto, perdendo o conteúdo editado sem aviso.

A v3.0.1 rastreia alterações ainda não salvas e confirma antes de:

- trocar de produto;
- sair da aba Produtos;
- abandonar a página.

Novos produtos também só entram no rascunho depois de Salvar.

### Upload de imagem

Na v3.0 a imagem era gravada no IndexedDB antes de o produto ser salvo. Descartar a edição podia deixar imagens órfãs.

Agora a imagem permanece pendente até Salvar produto.

### Miniatura automática

Ao enviar PNG, JPEG ou WebP, o Admin gera automaticamente uma miniatura de até 480 × 600 px, preservando a proporção e o formato sempre que possível.

Na exportação aparecem:

- Baixar principal;
- Baixar miniatura.

A principal vai para `img/`; a miniatura vai para `img/thumbs/`.

### Backup completo

O backup da v3.0 guardava apenas metadados das imagens.

A v3.0.1 inclui as imagens e miniaturas no JSON de backup como data URLs. A importação restaura catálogo, configuração e imagens locais.

O importador limita o arquivo de backup a 80 MB e ignora imagens incompatíveis ou maiores que 5 MB.

### Minha Conta

- armazenamento do perfil passa a tratar bloqueio de `localStorage`;
- remoção de dados atualiza a interface imediatamente;
- favoritos e lista respeitam `recursos.colecoes`;
- referências antigas a produtos removidos não desalinhavam mais cards e histórico.

## Compatibilidade

A arquitetura continua estática:

- GitHub Pages;
- Netlify;
- hospedagem HTTP estática equivalente.

Nenhuma credencial ou token é necessário no navegador.
